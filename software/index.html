Open science

Software

Open-source libraries developed with the SNA@KDD team, from network analysis toolkits to LLM-powered social twins and their analytics.

Social twins

The YSocial ecosystem

Simulate social platforms with LLM agents, then analyse what happened.

YSocial

Social media digital twin

Simulate online social platforms populated by LLM-driven agents to study recommender systems, moderation, misinformation and opinion dynamics.

CodeWebsite

ySights

Insights from YSocial simulations

Python library to query, analyse and visualise YSocial simulation data, from interaction networks to opinion and content dynamics.

CodeDocs
Network science

Network analysis libraries

Python libraries for communities, diffusion and temporal networks, built on top of NetworkX.

CDlib

Community discovery library

Dozens of community detection algorithms, evaluation scores and visualisations under a single, unified Python API.

CodeDocs

NDlib

Network diffusion library

Epidemic and opinion dynamics models on static and dynamic networks, with a simulation REST service and visual front-end.

CodeDocs

DyNetX

Dynamic network library

Temporal networks (snapshots and interactions) as a natural extension of NetworkX.
